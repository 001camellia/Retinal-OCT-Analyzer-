# Retinal-OCT-Analyzer - Fundus OCT Image Disease Analysis Tool

## 📁 Project Overview
This project utilizes fundus OCT image data provided by the Asia-Pacific Ophthalmic Society Big Data Competition (APOSBIG). Through image processing and deep learning techniques, it enables automated screening and analysis of retinal diseases. I was responsible for model modification.

## 🎯 Main Steps
1. **Macular Region Segmentation:** Precisely segment the fundus macular region from the original OCT images.
2. **GAN-based Image Enhancement:** Utilize generative adversarial networks to enhance image quality and improve analysis effectiveness.
3. **Disease Analysis:** Perform multi-class eye disease detection based on the processed images.
